# Transformer for Shakespeare Text

Train a Transformer language model on Shakespeare’s works to learn character-level/text-level patterns and generate text in a Shakespearean style.

## Overview
- Implemented a Transformer from scratch
- Trained on Shakespeare corpus
- Demonstrates language modeling and text generation

## Dataset
Shakespeare text corpus preprocessed for training.

## Methods
- Tokenization
- Transformer architecture (multi-head attention + feed-forward)
- Training loop with loss tracking
- Text generation sampling
